**Priority:** P2 / P3

**Blocks:** nothing
**Estimated risk:** Low

---

## 1. Objective

Close the cleanup class: **D-017** (hard-coded Persian strings and prompts), **D-024**'s
determinism sibling (**R-024**), **D-025** (dead modules), **D-027** (repo hygiene), the shim
removals (**ADR-013**), and the accessibility/i18n baseline.

## 2. Scope

1. **Remove all compatibility shims** and their re-exports:
   `SHIM-001` (V1 project reader), `SHIM-002` (`ExportMediaRegistry` re-export),
   `SHIM-003` (old-path re-exports), `SHIM-004` (`410 Gone` handlers),
   `SHIM-005` (`DEFAULT_CAPTION_FPS` alias).
2. **Delete `audit/`-era dead code** and dead modules: `src/lib/webcodecs-export.ts` (verify it
   is unreferenced first), `src/core/commands/propertyCommands.ts` and
   `cyberpunkSubscribeCommands.ts` (1-line stubs), and any module with zero importers — each
   deletion verified by a reference search, never by assumption.
3. **Repo hygiene**: delete the nine scratch files at the root (`inspect.txt`,
   `phaseG_test_output.txt`, `phaseG_test_output2.txt`, `video_export_chunk.txt`,
   `fix_typecheck.py`, `find_all_use_effects.cjs`, `find_literals.cjs`, `find_loops.cjs`,
   `find_render_setState.cjs`, `archive_integrity.json`, `metadata.json`, `resolution-test/`);
   rename `package.json` `name` from `"react-example"` to `"neural-pro"`.
4. **i18n** per [../../operations/i18n.md](../../operations/i18n.md): extract every user-visible
   literal into `src/i18n/`; error messages keyed by `errorCode`; `lang`/`dir` set at the
   document root; a lint rule banning JSX text nodes and literal toasts; a static test failing
   on non-Latin script outside `src/i18n/**` and `server/prompts/**`.
5. **Determinism**: content-derived caption ids (`sha1(start|end|text)`) replacing
   `Math.random()`; `waveformData` derived from decoded audio or not persisted; a test asserting
   the same input yields an identical document hash.
6. **Accessibility baseline**: accessible names on every interactive element, focus management
   on modal open/close, keyboard parity for pointer interactions, contrast ≥ 4.5:1.
7. **Remove the `[data-export-media-clip-id]` attribute** from `VideoPlayer` (its only consumer
   was the deleted registry) — verify by search first.
8. **Final documentation pass**: ensure every document's status reflects reality; the risk,
   invariant and gate tables are current.
