## 1. Objective

Make the service deployable and observable, and remove latent security/env defects.
Closes **D-008**, **D-012**, **D-013**, **D-015**, **D-021**, **D-023** (server half),
**D-028**, **S-5 … S-12**.

## 2. Scope

1. **Port contract**: `const port = Number(process.env.PORT) || 3000`; bind `0.0.0.0`
   (`server.ts:197` currently hard-codes 3000). Cloud Run injects `PORT` (default 8080).
2. **Environment contract**: startup validation; structured `env.report` line (names only);
   `.env.example` committed with the full variable list
   ([../../contracts/environment.md](../../contracts/environment.md)).
3. **Remove `better-sqlite3`** from `package.json` (0 references, breaks `npm install`).
4. **Remove the `define` secret mechanism** in `vite.config.ts` (D-021) and add a build-time
   assertion that no `AIza…` / `GEMINI_API_KEY=` value exists in `dist/**`.
5. **Health endpoints**: `/api/health` with a capability block; `/api/health/ai`.
6. **Security headers + CSP** per [../../security/security-model.md](../../security/security-model.md) §9.
7. **Structured logging** replacing `console.log` with emoji/Persian strings
   ([../../operations/logging.md](../../operations/logging.md)); request logging with
   `requestId`; no secret, prompt, or response body ever logged.
8. **Graceful shutdown**: `SIGTERM` → stop accepting → drain → exit 0.
9. **Error boundary** at the app root and around each panel (D-013); offers "undo last action"
   / "restore last save".
10. **Packaging**: `Dockerfile` (non-root, `ENV PORT`), `.dockerignore`, CI job that boots the
    container with `PORT=8080` and curls `/api/health`.
11. **Client capability probe**: required APIs probed at startup with an actionable message
    ([../../contracts/environment.md](../../contracts/environment.md) §4).
12. **Server captions FPS**: `projectFps` required on every caption endpoint
    (**shared with WP-09** — WP-07 owns the route signature, WP-09 owns the client call sites).
13. **Break the server → browser-feature import** (`server.ts:9` importing
    `captionTimecodeService`): move the timecode functions to `src/domain/captions/timecode.ts`.
14. **i18n of server errors**: server error strings are English + coded; the client localises
    by `errorCode`.

## 10. Acceptance criteria

1. The container boots with `PORT=8080` and `/api/health` returns 200.
2. `npm ci` succeeds in a clean container.
3. `NODE_ENV=production npm start` serves `/` and a deep route.
4. `SIGTERM` produces exit 0 within 10 s.
5. `.env.example` lists every variable in the environment contract, with empty values.
6. The error boundary renders on an induced throw.
7. CI is green including the container job.
