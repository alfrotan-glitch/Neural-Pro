# WP-08 — Module Layering & Decomposition

**Priority:** P2 (structural; high merge risk)
**Depends on:** WP-02, WP-03, WP-04, WP-05
**Blocks:** WP-12
**Concurrent-safe with:** WP-06
**Estimated risk:** High (it moves ~40 files)

---

## 1. Objective

Establish the four-layer structure and break the cycles (ADR-012). Closes **V1–V4**, **D-018**,
**D-019**; decomposes the god-components.

**Violations to remove:**

| ID | Violation |
|---|---|
| V1 | `core/engine/*` imports `features/video-studio/*` (`CanvasExportRenderer.ts:5-12`; `projectDuration.ts:1`) |
| V2 | `useProjectStore` ↔ `useHistoryStore` circular dependency |
| V3 | `server.ts:9` imports `features/video-studio/captions/services/captionTimecodeService` (fixed in WP-07) |
| V4 | domain logic duplicated to dodge the cycle (`clipTimelineDuration.ts`) |
| V5 | UI owns workflow semantics (`VideoStudioPro.tsx:433-705` — removed by WP-04) |
| D-018 | direct mutation of store state |
| D-019 | `(window as any).setViewMode` |

Plus: `VideoStudioPro.tsx` (1 855), `src/App.tsx` (~1 000 with business logic),
`InspectorEngine.tsx` (21+ `useState` mixing UI tabs with workflow flags: `isTTSGenerating`,
`isGeneratingCaptions`, `isTranslating`, `isRefiningCaptions`),
`VirtualizedTimeline.tsx` and its 905-line `useTimelineDragExecution`.

## 2. Scope

1. **Create `src/domain/**`, `src/app/**`, `src/infra/**`, `src/ui/**`** and move the files
   listed in [../../architecture/dependency-direction.md](../../architecture/dependency-direction.md) §3
   **step 1**. Behaviour-preserving moves with re-export shims (`SHIM-003`, owner WP-08,
   remove WP-12).
2. **Break the store cycle**: extract `CommandHistory` (plain class) from `useHistoryStore`; the
   project store subscribes through a callback registered in `src/app/composition.ts`.
3. **Server boundary**: `server/**` imports only `src/domain/**`.
4. **Infrastructure behind interfaces**: `ExportMediaPool`, `AssetRegistry`, `AiGateway`,
   `Logger` injected at composition time.
5. **Decompose `VideoStudioPro.tsx`** into `src/ui/studio/*` (after WP-04 removed the export
   workflow) and `InspectorEngine.tsx` into tab components + workflow-status hooks.
6. **Remove `(window as any).setViewMode`** — replace with an explicit prop/context.
7. **Remove direct state mutation** (D-018).
8. **Enable the lint boundaries** as errors.

**Explicitly out of scope:** rewriting `TextInspectorPanel`, `VirtualizedTimeline`'s drag
execution, or the animation subsystem. Moves and mechanical splits only.

## 10. Acceptance criteria

1. `npm run lint` passes with boundary rules as **errors**.
2. `madge --circular src/{domain,app,infra,ui}` reports no cycle.
3. Test #24 passes.
4. The full behavioural suite passes **unchanged** (no assertion edits).
5. `clipTimelineDuration.ts` exists in exactly one place (`src/domain/time/clipDuration.ts`).
6. `grep -rn "window as any" src/` → no match.
7. Every shim carries `SHIM-003` with owner and removal milestone.

## 11. Commit requirement

One commit **per move**, so a bisect can isolate a broken import:
`refactor(wp-08): move project types to src/domain/project`,
`refactor(wp-08): move time and duration logic to src/domain/time`,
`refactor(wp-08): move render model to src/domain/render`,
`refactor(wp-08): break the project/history store cycle`,
`refactor(wp-08): split VideoStudioPro into studio ui modules`,
`refactor(wp-08): split InspectorEngine into tab components`,
`fix(wp-08): remove window global mutation and direct state mutation`,
`test(wp-08): add layer, cycle and purity tests`.

## 12. Merge strategy

Rebase constantly. Because this WP touches the most files, it merges **after** the repair WPs
and **before** WP-12. If another WP needs a file mid-move, that WP wins and WP-08 rebases.

## 13. Conflict risks

| Risk | Mitigation |
|---|---|
| Massive diff, hard to review | one commit per move; no behaviour change in a move commit |
| Re-export shims mask the real import graph | shims are time-boxed (`SHIM-003`, removed in WP-12) and counted by a test |
| Decomposition of `VideoStudioPro` breaks the export workflow | WP-04 has already extracted it; decompose the remainder only |
| `VirtualizedTimeline` regression | out of scope by design; move only |

## 14. Rollback

Revert commit-by-commit. Because moves are behaviour-preserving, a partial revert is safe up to
any commit boundary.
