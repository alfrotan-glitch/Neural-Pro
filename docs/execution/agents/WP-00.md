# WP-00 — Verification & Tooling Baseline

**Priority:** P0 (unblocks every other WP)
**Depends on:** nothing
**Blocks:** everything
**Estimated risk:** Low

---

## 1. Objective

Make "done" verifiable. Today `npm test` is 92.7 % grep assertions, there is no lint, no CI, no
browser runtime, and the six audit reproductions are not wired into anything. Until this WP
lands, no work package can prove a claim.

## 2. Scope

1. **Test harness:** `node:test` + `tsx` runner wired to `npm test`; `vitest` +
   `@testing-library/react` + `jsdom` for component/DOM tests; `fast-check` for properties.
2. **Static gates:** ESLint (typescript-eslint) + `eslint-plugin-boundaries` (config from
   [../../architecture/module-boundaries.md](../../architecture/module-boundaries.md)) +
   `madge` for cycle detection; Prettier.
3. **Reproduction runner:** `npm run repro` executes all six scripts and reports exit codes
   individually; wire into CI as **allowed-to-fail** for the scripts whose defects are not yet
   fixed, with an explicit allowlist that names the owning WP and is expected to shrink.
4. **Browser runtime:** install Playwright Chromium; add `npm run test:browser`; record the
   WebCodecs capability matrix (`VideoEncoder.isConfigSupported` per codec).
5. **CI:** GitHub Actions running `npm ci` → `typecheck` → `lint` → `test` → `repro` → `build`
   → (container boot from WP-07).
6. **Resource probe:** `tests/harness/resourceProbe.ts` instrumenting
   `URL.createObjectURL`/`revokeObjectURL`, `setInterval`/`clearInterval`,
   `setTimeout`/`clearTimeout`, `addEventListener`/`removeEventListener`, `VideoFrame.close`,
   `ImageBitmap.close`, `AudioContext.close`.
7. **Fixture media generator:** deterministic synthetic video/audio produced locally (canvas +
   `MediaRecorder` at build time, or committed small fixtures) so no test requires network
   media.
8. **Test taxonomy:** move the 177 grep-style files to `tests/static/` with a header
   `// CLASS: static — asserts a source property, not behaviour`, and add
   `tests/composition.test.js` asserting that no file outside `tests/static/` is grep-only.

## 10. Acceptance criteria

1. `npm ci` succeeds in a clean container.
2. `npm run typecheck && npm run lint && npm test && npm run build` all succeed in CI.
3. `npm run repro` executes all six scripts and prints six exit codes without modifying them.
4. `npx playwright --version` works and Chromium launches.
5. The capability matrix document exists with real `isConfigSupported` results.
6. `tests/composition.test.js` fails if a grep-only file is placed in `tests/unit/`.
7. CI is green on a clean checkout, with the reproduction allowlist recorded.

## 13. Conflict risks

| Risk | Mitigation |

| Playwright download blocked by network | Record `BLOCKED` for Stage D; do not fake it. |
