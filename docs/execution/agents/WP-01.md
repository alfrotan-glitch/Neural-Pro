# WP-01 — Server Security Boundary

**Priority:** **P0**
**Depends on:** WP-00
**Blocks:** WP-09 (migrates onto the new operations)
**Concurrent-safe with:** WP-05, WP-08
**Estimated risk:** High (it deletes a working-ish API surface)

---

## 1. Objective

Remove the two P0 security surfaces and establish the server as an allowlisted, validated,
authenticated boundary.

* **D-002 / S-1:** `POST /api/generateContent` forwards the request body verbatim to
  `ai.models.generateContent(req.body)` (`server.ts:232`). An anonymous caller controls model,
  contents, system instruction, generation config, tools and safety settings. Reproduced:
  outbound request with attacker-chosen model and system instruction.
* **D-003 / S-2:** `/api/export/*` writes files and spawns a process; authorisation is gated on
  `NODE_ENV === 'production'`, so it is open everywhere else. Reproduced: anonymous request
  created `/tmp/session_<hex>` and reached `spawn ffmpeg ENOENT`.
* **S-4:** frame uploads allow ~7.2 GB/min/IP of disk writes.
* **D-023:** six hard-coded `/tmp/session_…` paths.

## 2. Scope

1. **Delete** `/api/export/start`, `/api/export/upload-frame`, `/api/export/upload-frames`,
   `/api/export/upload-audio`, `/api/export/finish`, the export session table, the session GC
   timer, `ffmpegSupportsEncoder`, `FinalizeResponse`, and every `/tmp` path (ADR-004).
2. **Delete** `/api/generateContent` (ADR-005). Replace with a `410 Gone` handler for one
   release (`SHIM-004`, owner WP-01, remove WP-12) returning a migration note.
3. **Add** the operation allowlist: `/api/ai/script`, `/api/ai/speech`,
   `/api/captions/generate`, `/api/captions/refine`, `/api/captions/parse-srt`,
   `/api/captions/export-srt` — schemas per [../../contracts/api.md](../../contracts/api.md).
4. **Add** `server/config/models.ts` (the only place model ids may appear) and
   `server/prompts/*.ts` (the only place instructions may appear) — ADR-008.
5. **Add** session-token authorisation (ADR-014): `GET /api/session`, HMAC-signed, short-lived,
   scope-bearer; protected routes require `Authorization: Bearer <token>`; **never** gated on
   `NODE_ENV`.
6. **Add** rate limiting per IP **and** per token (30/10 text/speech per IP, 60/20 per token).
7. **Add** request timeouts (`AbortSignal.timeout`) and the typed error mapping from
   [../../contracts/errors.md](../../contracts/errors.md).
8. **Add** output schema validation for AI responses ⇒ `502 AI_RESPONSE_INVALID`.
9. **Add** `/api/health` capability block and `/api/health/ai`.
10. **Add** security headers ([../../security/security-model.md](../../security/security-model.md) §9).

## 10. Acceptance criteria

1. All five P0/P1 surfaces above are unreachable or authenticated.
2. Every test in §8 passes; T-01 and T-02 fail on the pre-change commit and pass after (record
   both runs).
3. `grep -n "spawn(" server.ts` → no match; `grep -n "/tmp/" server.ts` → no match.
   (**Supporting static check only.** The runtime capability question — native binaries,
   subprocess execution, FFmpeg, packaged binaries, exec permissions — is settled by the
   **AS-13 investigation** in WP-13, and is not concluded by this grep.)
4. No model id string exists outside `server/config/models.ts` (static assertion).
5. `GEMINI_API_KEY` absent ⇒ every AI route returns 503 `AI_NOT_CONFIGURED`, never 200.
6. The full existing suite still passes (no client call sites changed yet — WP-09 follows).

> **Note on ordering:** removing `/api/generateContent` breaks the client's podcast/TTS flows
> **until WP-09 lands**. That is intentional and must be recorded in the PR: the alternative
> (shipping an unauthenticated metered passthrough) is the P0. If the branch must remain
> demoable between the two WPs, keep the `410` handler and document the gap.

## 13. Conflict risks

| Risk | Mitigation |
|---|---|
| `server.ts` is contended (WP-07, WP-09) | strict order: WP-01 → WP-07 → WP-09; each rebases |
| Client breaks until WP-09 | documented above; the 410 handler makes the break explicit |
| Rate-limit tests are time-sensitive | inject a clock; no wall-clock sleeps |

## 14. Rollback

Revert the series. Because `/api/generateContent` is only `410`-ed (not deleted) inside this
WP, a revert restores behaviour without data loss. No persistence is touched.
