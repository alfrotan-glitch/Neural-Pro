# WP-11 — Resource Lifecycle & Duration Authority

**Priority:** P1
**Depends on:** WP-05
**Blocks:** WP-12
**Concurrent-safe with:** WP-01
**Estimated risk:** Medium

---

## 1. Objective

Every acquired resource is released (INV-008), measured duration is authoritative (INV-011),
and one fps authority feeds every consumer (INV-013). Closes **D-014**, **D-016**, **D-020**,
**D-024**, **R-011**, **R-012**, **R-027**.

## 2. Scope

1. **Object-URL discipline**: `AssetRegistry.resolveUrl`/`releaseUrl` are the only mint/revoke
   sites (WP-05 provides them). Fix every other site:
   * `App.tsx` — TTS/generated-audio URLs replaced without revoke (**0 revoke calls today**);
   * `audioExtractionService.ts` lines 211, 223, 234 — three URLs, no revoke;
   * `VirtualizedTimeline.handleLinkOrReplaceMediaFile` (~904) — one URL per call, never
     revoked;
   * `ResourceSidebar` (249–272) — revokes only *unreferenced* URLs on unmount; make it
     unconditional with a reference count.
2. **`ondequeue` leak (D-016)**: the 100 ms timeout path never restores the previous handler —
   199 stale closures per 200 stalled frames. Restore it, or move to
   `addEventListener(..., { signal })` with an `AbortController` scope.
3. **`AudioMixController`** (240, owns the single interactive `AudioContext` + `masterGain`):
   add an explicit `dispose()` and call it on unmount / teardown.
4. **Duration authority (ADR-010, D-024)**: use the **measured** duration everywhere;
   `VideoStudioPro.tsx:216` must not use `state.totalDuration` for a generated clip's
   `duration`/`trim.out`; remove the `30.0`/`10.0` defaults in `ResourceSidebar`; revalidate
   persisted durations against the asset record on load.
5. **FPS authority (D-020)**: `RenderFpsAuthority` threaded into frame count, encoder config,
   frame timestamps, progress and caption timecodes.
6. **Audio sample rate (R-027)**: one `AudioRenderSampleRate` authority with an explicit resample
   step (currently `OfflineAudioContext(…, 44100)` at the call site vs `audioBuffer.sampleRate`
   for the encoder).
7. **Muxer disposal on abort** — release in `finally` for every terminal path.
8. **Balance probe** wired into tests for all six scenarios (success, failure, cancel, timeout,
   unmount, second run).
