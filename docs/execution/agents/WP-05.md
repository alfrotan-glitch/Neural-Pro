# WP-05 — Persistence & AssetRegistry

**Priority:** P1
**Depends on:** WP-00
**Blocks:** WP-02 (needs `AssetId` + the registry interface), WP-11
**Concurrent-safe with:** WP-01, WP-03
**Estimated risk:** High (data-model change)

---

## 1. Objective

Durable assets and durable identity (ADR-006, INV-009). Closes **D-006**.

**Evidence:** `ResourceSidebar.handleFileUpload` (line 506) and
`VirtualizedTimeline.handleLinkOrReplaceMediaFile` (~904) assign `URL.createObjectURL(...)`
into `clip.properties.{videoUrl,audioUrl,imageUrl}`. Those strings are written verbatim into
`localStorage['video_studio_pro_project_v1_<name>']`. A `blob:` URL is scoped to the creating
document and dies with it, so on reload every user-uploaded asset is unresolvable — while the
save toast reports `"💾 Saved project successfully!"`.

## 2. Scope

1. **`AssetId`** (`as_<uuid>`) and `AssetRecord` per
   [../../contracts/media-assets.md](../../contracts/media-assets.md).
2. **`AssetRegistry`** (interface first — WP-02 consumes it) with an **IndexedDB**
   implementation: three object stores (`projects`, `assets`, `assetRecords`) in a versioned
   `neuralpro` database.
3. **`ProjectDocumentV2`** (`schemaVersion: 2`) per
   [../../contracts/persistence.md](../../contracts/persistence.md); `localStorage` keeps UI
   preferences only.
4. **Migration**: V1 reader shim `SHIM-001` (owner WP-05, remove WP-12) that migrates in
   memory; on save, resolvable `blob:` URLs are imported and replaced by `AssetId`s;
   unresolvable ones become `mediaMissing`.
5. **Relink UI**: a clip with `mediaMissing` shows an explicit affordance; export refuses to
   start (or, with explicit opt-in, excludes the clip **and** reports it).
6. **Object-URL ownership**: `resolveUrl`/`releaseUrl` are the only mint/revoke sites; tracked
   in a `Map<AssetId, Set<string>>`.
7. **`measure()`**: duration/dimensions/sample-rate/channels measured once at import and cached
   on the record (this is the input to WP-11's duration authority).
8. **Quota handling**: `PERSISTENCE_QUOTA` + orphan eviction; `navigator.storage.estimate()`
   surfaced on failure.
9. **Never-fake save**: `saveProject` returns `{ ok, warnings: MediaMissingWarning[] }`; the
   toast reflects warnings.

| Item | Path | Notes |
|---|---|---|
| Format + writer/reader | `src/infra/persistence/projectBundle.ts` | dependency-free ZIP (STORE), CRC-32 per entry, fixed DOS timestamps so the same project state yields identical bytes (R5) |

| Tests — format | `tests/persistence/08-project-bundle.test.mjs` | 17 groups: empty-profile round trip, determinism, CRC/checksum/order/content-hash tamper, version refusal, conflict, no half-import, partial bundles |
| Tests — UI path | `tests/persistence/10-bundle-controller.test.mjs` | 5 groups driving the real store + controller: save-then-bundle ordering, `.neuralpro` naming, no file offered when the save fails, reuse-into-same-profile vs restore-into-fresh-profile, a non-bundle file leaves the open project untouched, partial bundle imports with the clip intact and flagged |

Failure modes found while building it, and what was done:

* **Dedupe would break restored references.** `put` returns an existing `AssetId` when the same
  bytes are already stored. On import that silently repoints the document at somebody else's
  id. Fixed with `preserveIdentity` + an explicit `writtenId !== record.id` guard that fails the
  import instead.
* **A same-length payload swap passes the ZIP CRC.** Added the manifest `byteSize` + `contentHash`
  checks (import step 8) so substitution is caught, not just truncation.
* **A partial bundle must not look complete.** `missingAssets` is part of the manifest and is
  surfaced as a warning on both export and import; the clip is marked for relink, never deleted.

**Data-loss defect found and fixed while closing §2.8** (self-discovered, not reported):

Post-save garbage collection was scoped to the assets of *the project being saved*, but the
asset store is shared by every project. Saving project B therefore marked all of project A's
media as orphaned; the 7-day grace window was the only thing hiding it, and once A's media was
older than that, saving B destroyed it — verified by reproduction: `A bytes still readable?
false`, and A reopened with `mediaMissing: true`.

Fix: `collectAllReferencedAssetIds(documents)` unions the references of every stored document,
returns `null` when any document is unreadable (an unknown reference set reclaims nothing), and
is now the scope for both post-save collection and `registry.orphaned()`. Regression tests in
`05`: cross-project save, genuine orphan reclamation, and the unreadable-document stop.
