# WP-05 — Persistence & AssetRegistry

**Priority:** P1
**Depends on:** WP-00
**Blocks:** WP-02 (needs `AssetId` + the registry interface), WP-11
**Concurrent-safe with:** WP-01, WP-03
**Estimated risk:** High (data-model change)

---

## 1. Objective

Durable assets and durable identity (ADR-006, INV-009). Closes **D-006**.

**Evidence:** `ResourceSidebar.handleFileUpload` (line 506) and
`VirtualizedTimeline.handleLinkOrReplaceMediaFile` (~904) assign `URL.createObjectURL(...)`
into `clip.properties.{videoUrl,audioUrl,imageUrl}`. Those strings are written verbatim into
`localStorage['video_studio_pro_project_v1_<name>']`. A `blob:` URL is scoped to the creating
document and dies with it, so on reload every user-uploaded asset is unresolvable — while the
save toast reports `"💾 Saved project successfully!"`.

## 2. Scope

1. **`AssetId`** (`as_<uuid>`) and `AssetRecord` per
   [../../contracts/media-assets.md](../../contracts/media-assets.md).
2. **`AssetRegistry`** (interface first — WP-02 consumes it) with an **IndexedDB**
   implementation: three object stores (`projects`, `assets`, `assetRecords`) in a versioned
   `neuralpro` database.
3. **`ProjectDocumentV2`** (`schemaVersion: 2`) per
   [../../contracts/persistence.md](../../contracts/persistence.md); `localStorage` keeps UI
   preferences only.
4. **Migration**: V1 reader shim `SHIM-001` (owner WP-05, remove WP-12) that migrates in
   memory; on save, resolvable `blob:` URLs are imported and replaced by `AssetId`s;
   unresolvable ones become `mediaMissing`.
5. **Relink UI**: a clip with `mediaMissing` shows an explicit affordance; export refuses to
   start (or, with explicit opt-in, excludes the clip **and** reports it).
6. **Object-URL ownership**: `resolveUrl`/`releaseUrl` are the only mint/revoke sites; tracked
   in a `Map<AssetId, Set<string>>`.
7. **`measure()`**: duration/dimensions/sample-rate/channels measured once at import and cached
   on the record (this is the input to WP-11's duration authority).
8. **Quota handling**: `PERSISTENCE_QUOTA` + orphan eviction; `navigator.storage.estimate()`
   surfaced on failure.
9. **Never-fake save**: `saveProject` returns `{ ok, warnings: MediaMissingWarning[] }`; the
   toast reflects warnings.

1. Tests #10, #11 and the migration tests pass; #10 and #11 fail before the change.

3. `grep -rn "createObjectURL" src/` → only inside `AssetRegistry.resolveUrl`.
4. Export refuses to start (with a named clip) when an asset is missing.
5. `saveProject` returns warnings and the UI shows them.
6. No user-visible regression for remote-URL (demo) projects.

## Runtime reconciliation (2026-09-09)

| Item | Change |
|---|---|
| Rationale corrected | IndexedDB is chosen not merely because it is better than localStorage, but because the AI Studio Web App runtime provides **no server-side durable storage** ("We are working on adding direct support for storage in the future"). | Scope addition | Verify storage behaviour **inside the AI Studio frame** (`P-02`). If storage is partitioned or denied, this WP must make **project export/import (a portable project bundle)** the primary durability mechanism and treat IndexedDB as an accelerator |
