# WP-04 — Workflow Runtime (Export)

**Priority:** P1
**Depends on:** WP-03
**Blocks:** WP-10
**Concurrent-safe with:** WP-01, WP-05
**Estimated risk:** Medium

---

## 1. Objective

Run export (W4) on a real state machine with one dispatch authority, correct cancellation and
observable progress (ADR-003, ADR-011, INV-007). Closes **D-010**, **R-014**, **R-020**,
**R-031**.

**Evidence (D-010, `audit/repro-export-queue.mts` → exit 1):**
```
CASE 1  job B: cancelQueuedJob → executeJob → job still ran            → DEFECT
CASE 2  job C: cancelJob during render → status stays 'rendering'      → DEFECT
```
Root cause: `RenderPipeline.cancelJob` bumps/deletes the run token **before** aborting, and
`executeJob`'s `if (!isCurrentRun(jobId, runToken)) return false` then skips the status write.
For a queued job there is no `AbortController` at all, so only the token is deleted — which
`executeJob` immediately re-creates.

**Evidence (R-014):** three dispatch authorities — `VideoStudioPro.beginExport()` →
`void renderPipeline.renderJob`, `RenderPipeline.executionTail`, and
`ExportQueueManager`'s `setInterval(1500)` `runOrchestrator` re-dispatching every `waiting`
job. Two deadlock hypotheses were tested executably and **disproved**
(`audit/repro-queue-deadlock.mts` → exit 0): duplicate dispatch is absorbed by the
`job.status !== 'waiting'` guard, and N parallel jobs over one slot all complete. The guard
stays.

## 2. Scope

1. **Implement `WorkflowRuntime`** per
   [../../architecture/workflow-architecture.md](../../architecture/workflow-architecture.md) —
   run state machine, transition table, retry/timeout policies, checkpoints, idempotency,
   `RunScope` disposers, structured events.
2. **Define W4 export** per [../../workflows/export.md](../../workflows/export.md) — 8 steps.
3. **Collapse dispatch to one authority**: `RenderPipeline` becomes a thin adapter; its
   `executionTail` serialisation is replaced by the runtime's concurrency policy
   (`maxConcurrentExports`, default 1).
4. **Delete the `setInterval(1500)` orchestrator** in `ExportQueueManager`. The queue is driven
   by state transitions.
5. **Fix the cancel bug** at its root: abort **then** write status; a queued run records a
   cancel intent that prevents start.
6. **Honour or remove `processMode: 'parallel'`** — if removed, remove the UI option in the same
   commit.
7. **Decompose `VideoStudioPro.tsx`'s export effect** (`useEffect([isExporting])`, ~270 lines)
   into the workflow; React subscribes via `useWorkflowRun(runId)`.
8. **Job status mirroring is one-way**: `runtime → useExportStore`. UI actions are intents.
